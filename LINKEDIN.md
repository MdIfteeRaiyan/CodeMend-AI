# DebugTest — LinkedIn launch kit

## Project title

**DebugTest — Test-driven debugging workspace**

## Portfolio description

DebugTest is a learning-first debugging workspace that helps programmers move from a failing program to a verified repair. It combines guided diagnosis, progressive hints, editable test cases, language-specific practice, and a secure execution-provider architecture across twelve programming languages.

## Launch post

I’m excited to share **DebugTest v3**, a complete redesign of my debugging and programming-learning project.

Instead of only returning an answer, DebugTest guides learners through a practical loop: **Write → Scan → Diagnose → Test → Resolve**. The new release includes a rebuilt animated interface, a diagnostic console, editable test cases, progressive hints, proficiency tracking, 24 practice challenges, local learning progress, and support for Python, C, C++, Java, JavaScript, TypeScript, C#, Go, Rust, PHP, Kotlin, and Ruby.

I also designed the execution layer responsibly: the public preview never runs unrestricted code inside Vercel. It can connect to a separately isolated, rate-limited runner through a protected server adapter, while remaining honest when that service is not configured.
